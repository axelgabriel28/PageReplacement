# Page Replacement Simulator

Simulate FIFO, LRU, and Optimal page replacement with Python.

**Run in a browser:** [Open the simulator](https://axelgabriel28.github.io/PageReplacement/). The page loads `page_replacement.py` from this repository and runs it with Pyodide. An internet connection is needed to load Pyodide.

**Run locally:** Install Python 3, then run `python page_replacement.py` for the desktop interface or `python page_replacement.py --cli` for the console. No Python packages are required. Run `python page_replacement.py --test` to check the algorithms.
